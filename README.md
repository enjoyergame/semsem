# Furry Porn  
  
Семестровый проект: Разработка 2.5D-игры на чистом C и Win32 API.  
Игра представляет собой шутер от первого лица (FPS) в лабиринте, написанный с нуля без использования сторонних движков. Графика реализована с помощью математического алгоритма **Raycasting** (как в классическом DOOM) и отрисована через стандартный Windows GDI.  

## 📜 Описание игры  
Вы находитесь в огромном лабиринте (32x32). Ваша цель — найти светящийся зеленый портал выхода, отбиваясь от врагов и следя за уровнем здоровья и патронов.  
* **Враги:** Зеленые монстры (ближний бой) и Фиолетовые монстры (стреляют фаерболами).  
* **Предметы:** Аптечки (+50 HP) и Коробки с патронами (+10 Ammo).  
* Игра поддерживает **локальный кооператив** (Split-Screen) — второй игрок может присоединиться для совместного прохождения!  
  
## 🎮 Управление  
**Глобальное:**  
* `F11` — Переключение полноэкранного режима (Borderless Fullscreen).  
* `R` — Возврат в главное меню.  
* `1` — Запуск SOLO режима.  
* `2` — Запуск CO-OP режима (Разделенный экран).  
  
**Игрок 1 (Верхний экран):**  
* `W, A, S, D` — Передвижение и повороты камеры.  
* `Space (Пробел)` — Стрельба.  
  
**Игрок 2 (Нижний экран - CO-OP):**  
* `Стрелочки (Up, Down, Left, Right)` — Передвижение и повороты камеры.  
* `Enter` — Стрельба.  
  
## 🛠 Инструкция по сборке  

* gcc main.c core.c ui.c -o game.exe -lgdi32 -lmsimg32 -std=c11 -Wall -Wextra

**Требования:**  
* Компилятор C (GCC / MinGW)  
* ОС Windows

Реализованные модули (Архитектура)  
Проект строго разделен на независимые модули по паттерну State:  
core.h / core.c — Модуль игровой логики. Содержит математику Raycasting'а (алгоритм DDA), ИИ врагов, систему коллизий и обработку предметов. Не содержит ни одного вызова Win32 API.  
ui.h / ui.c — Модуль интерфейса. Отвечает за создание окна, обработку ввода клавиатуры без залипания (GetAsyncKeyState) и GDI-отрисовку (двойная буферизация, StretchBlt, TransparentBlt, AlphaBlend).  
main.c — Точка входа. Содержит стабильный игровой цикл с высокоточным таймером QueryPerformanceCounter.  
texture_gen.c — Независимый модуль процедурной генерации текстур и сохранения их в формат 24-bit BMP.
